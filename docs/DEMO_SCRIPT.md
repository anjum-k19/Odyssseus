# Odysseus Demo Script (2–3 minutes)

1. **Intro**  
   “Odysseus is a browser extension that adds a reality layer to the web: it scores pages and lets you fact-check and trace sources.”

2. **Shield**  
   Open a news or article page. Show the overlay: Humanity, Integrity, Rhetoric. Explain: “We don’t reprocess; the backend stores results by URL so repeat visits are instant.”

3. **Litmus**  
   Select a claim on the page, right-click, “Odysseus Check.” Show the tooltip with verdict and short explanation.

4. **Ariadne**  
   Click “Link graph (Ariadne)” in the overlay. Show the list of links and types (e.g. original source, same network). Mention broken-chain alerts if any.

5. **Oracle / Chorus (optional)**  
   “The same backend supports chat with the page and alternative perspectives via the API; we can wire these into the extension UI next.”

6. **Outro**  
   “Odysseus uses Valkey for persistence, Gemini for analysis, and a configurable model so we can swap in newer models without code changes.”
